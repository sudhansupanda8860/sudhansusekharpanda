# Sudhansu Sekhar Panda Portfolio Website

Static portfolio site. No build step, no framework. Runs on GitHub Pages, Netlify or any static host.

## Files
- index.html : page structure and SEO tags
- assets/js/data.js : ALL website text. Edit this file to change content.
- assets/js/main.js : renders data.js into the page. No need to edit.
- assets/css/style.css : colours and fonts (variables at the top)
- assets/resume/ : resume PDF and DOCX used by the Download button
- assets/img/ : favicon and profile photo

## Update content
1. Open assets/js/data.js (on GitHub: click the file, then the pencil icon).
2. Change text inside the quotes only. Keep commas and brackets.
3. Add a photo: upload it to assets/img/ as profile.jpg and set "photo": "assets/img/profile.jpg".
4. Fill in the education entry when ready.
5. Commit. The live site updates in 1 to 2 minutes.

## Host on GitHub Pages
1. Create a public repo named sudhansupanda8860.github.io
2. Upload every file in this folder to the repo root (index.html at the top level)
3. Settings > Pages > Deploy from a branch > main / (root) > Save
4. Live at https://sudhansupanda8860.github.io in 1 to 3 minutes
